# Documentación RestaurantePro

Este directorio contiene toda la documentación relacionada con el sistema RestaurantePro para la gestión del restaurante.

## Estructura de la documentación

- **analisis-diseno/**: Documentos de análisis y diseño del sistema
  - Casos de uso
  - Diagramas de flujo
  - Modelos de datos
  
- **requisitos/**: Requisitos funcionales y no funcionales
  - Historias de usuario
  - Criterios de aceptación
  - Backlog del producto
  
- **arquitectura/**: Documentación de la arquitectura del sistema
  - Diagrama de componentes
  - Patrones de diseño aplicados
  - Decisiones técnicas
  
- **diagramas/**: Diagramas del sistema
  - Diagramas UML (Clases, Secuencia, etc.)
  - Diagramas de Entidad-Relación
  - Flujos de trabajo
  
- **prototipos/**: Diseños y mockups de la interfaz de usuario
  - Wireframes
  - Prototipos de alta fidelidad
  - Guía de estilos
  
- **manuales/**: Manuales para usuarios y desarrolladores
  - Manual de usuario
  - Manual de instalación
  - Guía de desarrollo
